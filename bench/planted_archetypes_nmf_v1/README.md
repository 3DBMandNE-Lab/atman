# planted_archetypes_nmf_v1

Non-negative planted-archetype fixture for NMF benchmarking. Contains 3 planted archetypes over 80 features and 120 samples, generated entirely from gamma distributions so all values are non-negative by construction. Sample mixing weights are drawn from Gamma(2.0, 1.0); archetype feature loadings from Gamma(1.0, 1.0) localised to a contiguous ~1/3 block of features per archetype, with sparse Gamma(0.3, 0.1) leakage elsewhere to mimic biological cell-type signatures; additive noise is Gamma(0.5, 0.2). RNG seed is 20260429 (numpy default_rng). Intended consumers: `atman bench decompose --fixture-nmf` for `atman.nmf`; the ICA-family tools (`atman.ica`, `atman.missingness-ica`) run against `bench/planted_archetypes_v1/` instead. Regenerate with `python3 generate.py` from this directory.
