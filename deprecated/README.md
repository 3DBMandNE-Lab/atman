# Deprecated Material

This folder holds material moved out of the active package root for manual inspection.

- `benchmarks/`: comparator and null-FPR experiments.
- `docs/`: manuscript drafts, findings, supplements, and planning docs.
- `example_data/`: extra non-Dube datasets.
- `generated/`: analysis outputs and manuscript build products.
- `scripts/`: historical Python and Bash analysis drivers.
- `local/`: local/editor/system files found during cleanup.

The active package root keeps the Rust workspace, packaging metadata, `docs/tutorial.md`, and `example_data/dube_heat_2023`, which is required by the integration tests.
